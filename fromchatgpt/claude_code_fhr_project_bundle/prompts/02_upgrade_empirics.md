# Prompt 02: Upgrade the empirical analysis

Read all project instructions and the completed audit/reconciliation files.

Execute Phase 3 and Phase 4 from `prompts/00_start_here.md`.

Prioritise analytical improvements that clarify the historical argument rather than adding complexity for its own sake.

The core tests are:

1. whether welfare-loan and public-pawnshop users differ in observable rehabilitation capacity, public-assistance history, material base, and shock profile;
2. whether purpose-specific loans align with corresponding needs;
3. whether histories of public credit use overlap with multiple other coping strategies;
4. whether the central findings survive reasonable alternative definitions, samples, models, and multiple-testing adjustments.

Explicitly revisit and improve any earlier analysis that:
- imposed an unjustified temporal order;
- called a q10 response “current” without documentary support;
- interpreted asset coefficients as unambiguous wealth or collateral effects;
- treated “low living ability” as an objective administrative score;
- used causal language;
- relied on one model or one missing-data rule.

Produce all main and appendix tables and figures, plus a short results memo that ranks findings as:
- highly robust;
- moderately robust;
- exploratory;
- unsupported.
