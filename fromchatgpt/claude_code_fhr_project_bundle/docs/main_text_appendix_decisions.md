# Main Text vs. Appendix Placement Decisions

**Date:** August 2, 2026  
**Phase:** 4 (Publication-Quality Outputs)

## Overview

This document records decisions about which tables and figures appear in the main text versus the appendix. The criterion is that main-text material must be essential to understanding the two central arguments: (1) institutional selection and household heterogeneity, and (2) credit layering versus substitution.

---

## Table Placement Decisions

### Table 1: Welfare Lending and Public Pawnshops, 1959–1963
- **Status:** Main text (Chapter 2)
- **Rationale:** Authoritative historical benchmark; part of existing Chapter 2; establishes macro context
- **Location:** Section 2.3 of institutional background

### Table 2: Household Characteristics by Institutional-Use Group
- **Status:** Main text (Chapter 3)
- **Rationale:** Essential descriptive foundation; shows heterogeneity across institutional groups; establishes that institutions served different populations
- **Location:** Section 3.1 of Data chapter

- **Historical importance:** HIGH—demonstrates observable differences between users

### Table 3: Institutional Selection Models (Welfare Loans and Public Pawnshops)
- **Status:** Main text (Chapter 5)
- **Rationale:** Core empirical result answering first central question; presents main selection coefficients for two institutions
- **Location:** Section 5.2 of Results chapter
- **Empirical strength:** Verified from Phase 1–2 reproduction
- **Historical importance:** HIGH—tests whether institutions served different populations by risk profile

### Table 4: Direct Welfare-Only vs Pawnshop-Only Comparison
- **Status:** Main text (Chapter 5)
- **Rationale:** Direct evidence that economic position, not shock type alone, distinguished institutional choice; highest R-squared (0.1197) suggests strong institutional sorting
- **Location:** Section 5.3 of Results chapter
- **Empirical strength:** Verified; clearest institutional differentiation
- **Historical importance:** HIGH—evidence for institutional complementarity rather than pure substitution

### Table 5: Purpose-Specific Targeting (conditional)
- **Status:** Appendix A (Section A.6)
- **Rationale:** Supportive evidence that welfare programmes reached intended populations; weaker than main narrative and interruptive
- **Location:** Appendix Table A9–A12
- **Empirical strength:** Verified; robust targeting effects
- **Historical importance:** MEDIUM—validates institutional measurement but not central to main story

### Table 6: Institutional-Use Histories and Layered Borrowing
- **Status:** Main text (Chapter 5)
- **Rationale:** Core evidence for second central argument (layering versus substitution); directly answers whether welfare lending displaced other credit mechanisms
- **Location:** Section 5.5 of Results chapter

- **Historical importance:** HIGH—evidence that welfare credit complemented rather than replaced older mechanisms

## Figure Placement Decisions

### Figure 1: Economic Growth and Residual Vulnerability, 1955–1965
- **Status:** Main text (Chapter 2)
- **Rationale:** Macro context from institutional background; existing in Chapter 2

### Figure 2: Credit and Coping Practices Landscape (conditional)
- **Decision:** OMIT FROM MAIN TEXT
- **Reason:** Redundant with Table 2 descriptive content; Table 2 already shows prevalence of institutional access and coping strategies
- **Alternative:** If retained, move to Appendix B as Appendix Figure B1
- **Rationale for omission:** Main-text space is better used for explanatory tables (Table 3, 4, 6) than for descriptive landscape that duplicates Table 2

### Figure 3: Correlates of Welfare-Loan and Public-Pawnshop Use
- **Status:** Main text (Chapter 5)
- **Rationale:** Visual comparison of institutional correlates makes coefficient differences immediately apparent; supports interpretation of institutional heterogeneity
- **Location:** Section 5.2 of Results chapter
- **Empirical strength:** Verified coefficients from Table 3
- **Historical importance:** HIGH—Figure makes institutional contrast visceral

### Figure 4: Combinations of Credit Strategies (conditional)
- **Decision:** APPENDIX PLACEMENT (Appendix Figure C1)
- **Reason:** While Figure 4 shows credit layering, Table 6 coefficients convey the same information more precisely. UpSet plot is visually complex and space-intensive
- **Alternative:** If retained in appendix, accompany with text noting that large pawnshop-pawning coefficient (37.7 pp) is the primary evidence for layered use
- **Rationale for appendix placement:** Main text is better served by parsimony; coefficient table more useful than combination plot for this audience

## Robustness and Sensitivity Analyses

### Leave-One-City-Out Analysis
- **Location:** Appendix A, Table A7
- **Decision:** Appendix
- **Rationale:** Necessary for credibility (shows results stable across cities) but not central to narrative; can be summarised in main-text robustness discussion

### Alternative Specifications (Logit, Probit, Alternative Asset Indices)
- **Location:** Appendix A, Tables A5–A8
- **Decision:** Appendix
- **Rationale:** Confirm robustness but are not the primary specifications; main text can note agreement with alternatives

### Diagnostics and Multicollinearity
- **Location:** Appendix A, Tables A15–A17 and Figures A1–A2
- **Decision:** Appendix
- **Rationale:** Standard verification tools; necessary for reproducibility audit but not essential to readers
